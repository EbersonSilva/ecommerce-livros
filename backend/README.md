Estrutura inicial do backend (Express + TypeScript)

Comandos:
- `npm install` -> instala dependências
- `npm run dev` -> roda em modo desenvolvimento (ts-node-dev)

API básica:
- GET /api/clientes
- GET /api/clientes/:id
- POST /api/clientes
- PUT /api/clientes/:id
- PATCH /api/clientes/:id/inativar

Observações:
- Repositório em memória por ora. Pode-se trocar por banco (Postgres/SQLite) posteriormente.
